Política de Privacidad

Última actualización: 14 de septiembre de 2026

MELOD♪A ("la Aplicación") es una aplicación de reproducción de música desarrollada por John Torres. Esta política de privacidad describe cómo se maneja la información cuando utilizas la Aplicación.

1. Información que recopila la Aplicación

MELOD♪A no recopila, almacena ni comparte datos personales identificables. La Aplicación funciona de la siguiente manera:

  • Archivos de música locales: La Aplicación accede únicamente a los archivos de audio almacenados en tu dispositivo para poder reproducirlos. Esta información no sale de tu dispositivo.
  • Conexión a internet: Se utiliza únicamente para buscar letras de canciones, contenido de YouTube y servir anuncios.
  • Notificaciones: Se utilizan para mostrar controles de reproducción en la barra de notificaciones del sistema.
  • Reproducción en segundo plano: Permite que la música continúe reproduciéndose cuando la Aplicación no está en primer plano.

2. Servicios de terceros

La Aplicación utiliza los siguientes servicios de terceros que pueden recopilar información:

  • YouTube API Services: La Aplicación utiliza la YouTube Data API v3 para buscar y reproducir contenido de YouTube. El uso de estos servicios está sujeto a las Políticas de Privacidad de Google. Al utilizar la Aplicación, aceptas los Términos de Servicio de la YouTube API.
  • Google AdMob: La Aplicación muestra anuncios a través de Google AdMob. Google puede recopilar y utilizar datos de acuerdo con sus Políticas de Privacidad. Puedes optar por no recibir publicidad personalizada en la configuración de tu dispositivo.

3. Permisos de la Aplicación

  • INTERNET: Para buscar letras, contenido de YouTube y servir anuncios.
  • READ_MEDIA_AUDIO / READ_EXTERNAL_STORAGE: Para acceder a los archivos de música en tu dispositivo.
  • FOREGROUND_SERVICE: Para mantener la música reproduciéndose en segundo plano.
  • POST_NOTIFICATIONS: Para mostrar la notificación de reproducción.
  • WAKE_LOCK: Para evitar que el dispositivo entre en modo suspensión durante la reproducción.

4. Almacenamiento de datos

La Aplicación almacena únicamente información local en tu dispositivo, como:

  • Canciones favoritas
  • Listas de reproducción creadas por el usuario
  • Historial de reproducción
  • Configuración de la aplicación (tema, ecualizador, etc.)

Esta información se almacena únicamente en tu dispositivo y no se transfiere a servidores externos.

5. Seguridad

La Aplicación no transfiere datos personales. La conexión con YouTube y otros servicios se realiza a través de conexiones HTTPS cifradas.

6. Privacidad de los niños

La Aplicación no está dirigida a niños menores de 13 años y no recopila información personal de menores.

7. Cambios en esta política

Esta política de privacidad puede actualizarse periódicamente. Los cambios se publicarán en esta misma página.
